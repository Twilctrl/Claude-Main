# breadcrumbs

Leave notes on parts of a codebase. When Claude reads or edits a matching file,
the note is handed to it right then — not in a CLAUDE.md it may have skimmed an
hour ago, but at the moment it's looking at the code the note is about.

Also: **time capsules**. Seal a note with a future date and it opens at the
first session on or after that day.

## Install

```
/plugin marketplace add twilctrl/claude-main
/plugin install breadcrumbs@claude-main
```

## Use

```
/breadcrumbs:crumb add src/billing/** Amounts are integer cents. Never use floats here.
/breadcrumbs:crumb add migrations/ Migrations are generated by `make migrate`; don't hand-write them.
/breadcrumbs:crumb capsule +6w Remove the legacy_auth feature flag — the rollout should be done by now.
/breadcrumbs:crumb capsule 2027-01-01 Bump the copyright year.
```

| Command | What it does |
| --- | --- |
| `/breadcrumbs:crumb` | List every crumb and capsule (sealed capsules stay hidden) |
| `/breadcrumbs:crumb add <glob> <note>` | Pin a note to files matching the glob |
| `/breadcrumbs:crumb capsule <date> <note>` | Seal a note; `<date>` is `YYYY-MM-DD` or `+10d` / `+3w` / `+6m` / `+1y` |
| `/breadcrumbs:crumb check <path>` | Which notes would fire for this path |
| `/breadcrumbs:crumb remove <id>` | Delete a crumb (`c1`…) or capsule (`t1`…) |

Writes go to the project (`.claude/breadcrumbs.json`) by default — commit it and
the whole team's Claude sessions get the same notes. Add `--scope user` for
private notes in `~/.claude/breadcrumbs.json`. Both files are always active.

## Matching

Globs are matched against the path relative to the project root. `*` crosses
directories (`src/*.py` matches `src/a/b.py`), and a bare directory like
`migrations/` covers everything below it.

## How it works

- A `PostToolUse` hook on `Read|Edit|Write|MultiEdit|NotebookEdit` checks the
  file against every crumb and returns matches as `additionalContext`. Each
  crumb fires **once per session**, so re-reading a file doesn't repeat it.
- A `SessionStart` hook opens due capsules and asks Claude to tell you about
  them in its first reply. Each capsule opens once per user per project;
  `remove` it when you're done with it.
- Per-session bookkeeping lives in `${CLAUDE_PLUGIN_DATA}` (or
  `~/.claude/plugin-data/breadcrumbs/`) and is pruned after a week.

Hooks fail open: a broken config means no note, never a blocked tool.

## Requirements

`python3` on `PATH` (standard library only).
