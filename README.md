# Claude-Main

Personal Claude Code plugins, published as a plugin marketplace.

```
/plugin marketplace add twilctrl/claude-main
```

## Plugins

| Plugin | Description |
| --- | --- |
| [prompt-prefix](plugins/prompt-prefix) | Put a phrase of your choosing at the start of every prompt you send. |
| [breadcrumbs](plugins/breadcrumbs) | Notes pinned to file paths that Claude sees the moment it touches those files, plus time capsules that open on a future date. |
| [scope-fence](plugins/scope-fence) | Fence Claude's edits to the paths a task is about, and cap files changed per session. |
| [session-receipt](plugins/session-receipt) | An itemised, till-style receipt of what a session did. |
