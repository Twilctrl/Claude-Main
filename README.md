# Claude-Main

Personal Claude Code plugins, published as a plugin marketplace.

```
/plugin marketplace add twilctrl/claude-main
```

## Plugins

| Plugin | Description |
| --- | --- |
| [prompt-prefix](plugins/prompt-prefix) | Put a phrase of your choosing at the start of every prompt you send. |

## Projects

| Project | Description |
| --- | --- |
| [feather-llm-keyboard](projects/feather-llm-keyboard) | Adafruit Feather RP2350 firmware that types a Raspberry Pi's local LLM output into a laptop as a USB keyboard. |
